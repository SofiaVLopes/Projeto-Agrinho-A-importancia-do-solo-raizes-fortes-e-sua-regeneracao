# Projeto Agrinho 2026: Raízes e Regeneração

## 🌿 Objetivo do Tema
Este projeto foi desenvolvido sob o tema "Agro forte, futuro sustentável: equilíbrio entre produção e meio ambiente". O objetivo principal é conscientizar produtores rurais e a comunidade escolar sobre a importância da agricultura regenerativa. Através de uma interface digital atraente e interativa, o site demonstra que a conservação do solo, a proteção das águas e a manutenção da biodiversidade andam lado a lado com a alta produtividade e lucratividade no campo.

## 🚀 Tecnologias Utilizadas
- **HTML5:** Estruturação semântica do conteúdo.
- **CSS3:** Estilização avançada, transições suaves, design responsivo (Media Queries) e gerenciamento de variáveis de cor.
- **JavaScript (ES6):** Manipulação dinâmica do DOM, validação de formulários e processamento lógico de dados em tempo real.

## 🎨 Identidade Visual e Mídias
A identidade visual foi construída de forma 100% autoral, utilizando uma paleta de cores orgânica (tons terrosos e verdes oliva) para refletir o conceito de "pé na terra". 
- Os elementos gráficos e o logotipo vetorizado foram customizados e exportados através da ferramenta **Canva** e tratados via código **SVG nativo** para garantir carregamento imediato e sem perda de resolução.

## 📦 Como Executar o Projeto
1. Baixe ou extraia a pasta completa do projeto garantindo que as subpastas `css/`, `js/` e `assets/` mantenham seus nomes originais.
2. Abra o arquivo `index.html` em qualquer navegador web moderno (Google Chrome, Mozilla Firefox, Edge ou Safari).
3. Interaja com o "Simulador Ambiental" preenchendo os campos e alterne entre os temas claro e escuro utilizando o botão no menu superior.
